### Контекстные роли

Компоненты не читают исходные цвета напрямую, а берут роли: `--c-bg`, `--c-card`, `--c-fg`, `--c-fg-2`, `--c-line`, `--c-control`, `--c-act`, `--c-act-hover`, `--c-act-fg`, `--c-link`, `--c-orn`. Светлый контекст задан в `:root`, класс `.dark` переключает роли на тёмные, `.light` возвращает светлые внутри тёмной секции (карточка квиза, реквизиты), `.sand` меняет только фон. Поэтому одна и та же кнопка `.btn--primary` на светлом зелёная с белым текстом, а на тёмном светло-зелёная с тёмным текстом.

### Действие и орнамент: почему два цвета

Цвет действия один, зелёный. Он отмечает только главное действие (WhatsApp, «Проверить», «Обсудить расчёт»), выбранный вариант и прогресс квиза, ползунки, итог калькулятора, цену главной услуги и текстовые ссылки. На тёмном фоне это `--accent-bright`, тот же оттенок, светлее, иначе не читается.

Охра (`--gold` / `--gold-deep`) введена в v2 как цвет орнамента, а не второй акцент. Обоснование: пользователь попросил выразительности, а тёплая охра из палитры Средней Азии (глина, медь, орнамент изразцов) даёт тёмно-зелёным блокам глубину и связывает сайт с аудиторией KG/TJ/UZ без флагов и этно-клише. Коралловый `#FF5747` из логотипа не взяли: рядом с зелёным он читается как ошибка или скидка. Правило: охра никогда не бывает заливкой кнопки, ссылкой или полем. Она рисует маршрут и точки городов, кайму и решётку, номера правил безопасности, цифры фактов, линию прогресса этапов, арки под портретами, подсветку страны в заголовке.

## Движение

Кривая одна на весь проект: `--ease: cubic-bezier(0.16, 1, 0.3, 1)` (экспо-выход). JS-твины чисел используют ту же экспо-функцию. Исключения с линейным временем: бегущая строка и вращение звезды в квизе (непрерывное движение), «дыхание» точек назначения на карте (ease-in-out).

| Токен | Длительность | Где |
| --- | --- | --- |
| `--dur` | 220 мс | Наведение, нажатие, смена цвета, иконки, меню |
| `--dur-enter` | 560 мс | Шаг квиза, вкладка документа, результат, раскрытие FAQ, ползунки, линия калькулятора |
| `--dur-reveal` | 900 мс | Появление блоков при скролле, шаг stagger 80 мс |
| `--dur-draw` | 1800 мс | Прорисовка линий маршрута, сдвиг 140 мс на линию |
| счётчики | 1400 мс | Цены, факты основателя |
| пересчёт калькулятора | 600 мс | Твин от показанного значения к новому |

Где что движется:

- Первый экран: H1 выезжает по словам из-под маски; линии «Бишкек, Ташкент, Душанбе → Москва, Петербург» рисуются через `stroke-dashoffset`; точки городов пульсируют; дом и ключ проявляются в конце. Каждые 3,2 с подсвечивается следующая страна: её линии, точка, подпись и название в заголовке. По активной линии едет точка. Наведение на вариант в карточке останавливает перебор, клик сразу открывает квиз со второго вопроса. Перебор и точка останавливаются, когда первый экран не виден.
- Бегущая строка продуктов (48 с на круг, пауза при наведении), разделитель звезда, не точка.
- Появление секций через IntersectionObserver, stagger у карточек; после появления атрибут снимается, чтобы задержка не мешала наведению.
- Этапы: линия заполняется по скроллу (`scaleY`), номер этапа заливается при прохождении, на десктопе липкий счётчик «N/5».
- Квиз: шаг вперёд въезжает справа, назад слева, варианты по очереди; прогресс `scaleX`; пункты результата по очереди.
- Калькулятор: числа пересчитываются твином, полоса «кредит / переплата» меняет пропорцию.
- Карточки, команда, офисы, иконки РФ: подъём и реакция только на устройствах с мышью (`hover: hover`).

Правила:

- Анимируются только `transform` и `opacity` (плюс цвет и фон на наведении). Ширина, высота и отступы не анимируются. Скролл-обработчик один, через `requestAnimationFrame`, сначала чтения геометрии, потом записи.
- `prefers-reduced-motion: reduce` выключает всё: блоки видны сразу, маршрут нарисован, бегущая строка становится статичным списком, нет пульса, твинов, магнита и автоперебора.
- Без JS всё видно: скрытие до появления включается классом `.js` на `<html>`.

| Лозунги без работы | Убрали, и ничего не сломалось |
| Второй цвет действия | Действие только зелёное; охра только орнамент, никогда кнопка или ссылка |

| Кнопка до объяснения | Сначала H1 с ответом «для кого», потом действие |
| Мёртвые серые кнопки | Занимают место |
| «Гарантируем одобрение», «100%», счётчики одобрений без основы | Так обещают мошенники; банк решает сам. Счётчики только по фактам с сайта клиента |
| Таймеры и счётчики срочности | Давление и недоверие |
| Стоковые фото, сгенерированные люди и офис | Доверие держится на правде |
| Флаги в переключателе языка и на карте | Язык не равен стране |
| Эмодзи в интерфейсе | Правило проекта |
| Декоративная анимация без смысла, анимация ширины и высоты | Тормозит на телефоне; движение должно объяснять |
| Анимация без варианта для reduced-motion | Доступность |
| Вымышленные данные без пометки `.mock-note` | Клиент примет пример за факт |
| Текст с переносами, вбитыми руками | Ломается на других ширинах |
