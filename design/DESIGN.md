# Планета-312: DESIGN.md (ЧЕРНОВИК)

Статус: черновик под концепцию A «Ясный договор» из `docs/brief.md`. Пока пользователь не выберет концепцию, значения не финальные. В код не переносить до утверждения.

## Палитра

| Токен | Значение | Где | Контраст |
| --- | --- | --- | --- |
| `--color-bg` | `#F6F4EE` | Фон страницы, тёплая бумага | |
| `--color-surface` | `#FFFFFF` | Карточки, поля ввода | |
| `--color-text` | `#16211C` | Основной текст, почти чёрный с зелёным | 15:1 на bg |
| `--color-text-2` | `#545E58` | Вторичный текст, подписи | 6,1:1 на bg |
| `--color-border` | `#E3DFD5` | Границы карточек, разделители | только декор |
| `--color-accent` | `#1E6B47` | Главное действие (WhatsApp и «Проверить»), критичное число (итог калькулятора, цена) | белый на нём 6,5:1; на bg 5,9:1 |
| `--color-danger` | `#B3261E` | Только ошибки полей формы | 6,5:1 на белом |

Акцент один, зелёный. Он продолжает текущий фирменный `#68a250` (тот на белом даёт 3,06:1 и не проходит AA). `--color-danger` считаем системным цветом, а не вторым акцентом: он появляется только при ошибке. Блок безопасности сделан без красного: обычная карточка с иконкой щита.

Вопрос к пользователю: допустимо ли такое исключение из правила «ошибка = акцент». Альтернатива: ошибка цветом `--color-text` с иконкой и рамкой.

## Шрифт

- Onest (SIL OFL 1.1), начертания 400 и 600. Табличные цифры (`font-variant-numeric: tabular-nums`) в ценах и калькуляторе.
- Покрытие проверено по cmap файла: русский, кыргызский (ң ө ү), таджикский (ҳ ҷ ӣ ӯ қ ғ), узбекская латиница (ʻ U+02BB). Запасной вариант с тем же покрытием: Inter.
- Свой хостинг, woff2, подмножества latin + cyrillic + cyrillic-ext.
- После вёрстки проверить глазами каждую языковую версию: в CSS стоит одно название, а буквы может рисовать запасной шрифт.

## Шкала текста (5 размеров, телефон / десктоп)

| Токен | Телефон | Десктоп | Где |
| --- | --- | --- | --- |
| `--text-xs` | 14 | 14 | Подписи, реквизиты |
| `--text-base` | 16 | 18 | Основной текст |
| `--text-lg` | 20 | 22 | Заголовки карточек |
| `--text-xl` | 26 | 36 | Заголовки секций |
| `--text-2xl` | 32 | 52 | H1, итог калькулятора |

Межстрочный интервал: 1,5 для текста, 1,15 для заголовков. Длина строки до 65 знаков. Учесть, что кыргызский и узбекский текст на 15–30% длиннее русского.

## Отступы и скругления

- Шкала отступов, кратна 4: 4, 8, 12, 16, 24, 32, 48, 64, 96.
- Поля карточки: 16 на телефоне, 24 на десктопе. Между секциями: 64 на телефоне, 96 на десктопе.
- Скругления: 8 у полей и кнопок, 12 у карточек. Таблетки не используем.
- Зона нажатия от 44 × 44.

## Иконки и компоненты

- Иконки Lucide, толщина линии 1,75, один размер 20 или 24. Иконки мессенджеров (WhatsApp, Telegram) берём из официальных брендбуков в монохроме, сами не рисуем.
- Компоненты: своя лёгкая система на токенах (Astro + CSS-переменные). Если понадобится библиотека, то одна и с темой проекта.
- Тени не используем, глубину дают граница и фон. Blur только у нижней панели мессенджеров на телефоне.

## Движение

- 200 мс, `cubic-bezier(0.2, 0, 0, 1)`. Анимируются только раскрытие ответа, шаг квиза и пересчёт итога калькулятора.
- `prefers-reduced-motion` выключает всё.

## Запретный список

| Нельзя | Почему |

| Мелкий текст капсом с разрядкой, заголовки капсом («ШЕСТЬ ГЛАВНЫХ ПРИЧИН», «ВНИМАНИЕ») | Маркер шаблона; капс читается как крик |

| Больше одного акцентного цвета | Сейчас их на сайте четыре |
| Кнопка до объяснения | Сначала H1 с ответом «для кого», потом действие |
| Мёртвые серые кнопки | Занимают место |
| «Гарантируем одобрение», «100%», «98%» без основы | Так обещают мошенники; банк решает сам |
| Таймеры и счётчики срочности | Давление и недоверие |
| Стоковые фото «семья с ключами», сгенерированные люди и офис | Доверие держится на правде |
| Флаги в переключателе языка | Язык не равен стране |
| Эмодзи в интерфейсе | Правило проекта |
| Текст с переносами, вбитыми руками («Поис / к объекта») | Ломается на других ширинах |
| Серый текст светлее `--color-text-2` | Нечитаемо на солнце (текущий `#a5a6a6` даёт 2,4:1) |

| Шрифт без проверенного покрытия KG/TJ/UZ (Manrope, Unbounded, Literata, Gilroy) | Буквы ҳ ҷ ң выпадают в запасной шрифт |
